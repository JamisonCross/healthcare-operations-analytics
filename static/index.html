MODEL INTERPRETATION

What moves the model’s prediction?

Signed logistic-regression coefficients. Numeric inputs use a one-standard-deviation change; category coefficients use one-hot coding. Magnitudes across these types are not directly comparable. Associations in generated data are not causal effects.
